# Праздничные композиции v2

Созданы встроенным image_gen 21 октября 2026 года по пяти изображениям пользователя. Прозрачные PNG хранятся в этой папке; art-data-v2.js содержит те же изображения как data URL для экспорта через file:// без загрязнения Canvas. Исходные изображения пользователя не перерисовывались и не изменялись.

## Промпт

Use case: ads-marketing. Generate one production-quality transparent PNG decorative overlay for an existing automotive sales collage, portrait 9:16. The user's five attached posters are STYLE REFERENCES ONLY. Do not render or alter any car, photo, logo, price, specifications, contact information or collage. Transparent alpha everywhere except decorative foreground objects. Match the luxury photoreal 3D materials, rich volume, glossy lighting and detail of the references, not flat clipart. Layout: substantive corner decoration at extreme upper left, a gracefully draped narrow decoration along the very top edge, a beautiful sweeping bottom border with denser bottom corners, subtle sparse edge sparkles. Keep the entire middle transparent, and top center/right transparent for separately typeset greeting. NO TEXT, NO LOGOS, NO CAR, NO opaque background, NO checkerboard rendered into pixels. Reusable luxurious foreground decoration layer, not a finished poster.

Варианты темы:

- winter: dark green snow-dusted fir, gold/red baubles, warm fairy lights, red berries, red/gold presents and snow, reference 1.
- defender: satin white-blue-red Russian tricolor, sculpted gold five-point stars and laurel leaves, reference 2.
- spring: pink tulips, delicate yellow mimosa, pink silk ribbon, gold dust and petals, reference 3.
- motorist: red light trails, curled black/white racing flags, red/silver confetti, reference 4.
- victory: red carnations, black/orange St George ribbon, gold stars and sparks, reference 5.

Для поздравлений используется локальный свободный [Marck Script из Google Fonts](https://github.com/google/fonts/tree/main/ofl/marckscript); лицензия сохранена в assets/fonts/MarckScript-OFL.txt. Шрифт встроен как data URL, сетевые запросы при работе генератора не нужны.
