# Генератор сторис «ТИТАН АВТО»

Локальная страница для создания единообразных автомобильных сторис 1080 × 1920 px.

## Запуск

Дважды щёлкните `index.html`. Установка и интернет не требуются. Интернет используется только для загрузки фирменных шрифтов; без него страница автоматически использует системные шрифты.

## Как пользоваться

1. Вставьте объявление целиком и нажмите «Разобрать текст».
2. Проверьте автоматически заполненные поля. В сторис попадут только первые три характеристики.
3. Добавьте фотографии. Первая сторис объединит первые шесть кадров: одно главное фото и пять дополнительных.
4. Следующие сторис показывают фотографии со второй и далее крупным планом. Последней всегда добавляется фирменная сторис с другими предложениями и преимуществами «Титан Авто».
5. Перетаскивайте миниатюры, чтобы поменять порядок и назначить главное фото. В коллаже нажмите нужную ячейку, затем двигайте снимок; колесо мыши меняет масштаб.
6. Верхняя кнопка сохраняет всю серию отдельными PNG через системное меню телефона, нижняя — только открытую сторис.
7. Перед финальной страницей выберите один из пяти дизайнов. Тексты выбранного варианта настраиваются в блоке под выбором дизайна.

Фирменный логотип добавляется автоматически и меняет цвет основной надписи для контраста с фотографией. Текстовые настройки сохраняются в браузере автоматически; сами фотографии не сохраняются.

## Публикация

Проект рассчитан на GitHub Pages и не требует сервера или базы данных. Фотографии обрабатываются локально в браузере пользователя и не отправляются на хостинг.
