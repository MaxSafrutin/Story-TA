# Генератор сторис «ТИТАН АВТО»

Локальная страница для создания единообразных автомобильных сторис 1080 × 1920 px.

## Запуск

Дважды щёлкните `index.html`. Поднимать локальный сервер, устанавливать программы или запускать команды не требуется. Интернет используется только для загрузки фирменных шрифтов; без него страница автоматически использует системные шрифты.

Фоновая оптимизация фотографий использует встроенный Web Worker браузера. Он создаётся непосредственно кодом страницы и не является отдельной утилитой или службой. Если этот механизм недоступен, автоматически включается совместимый резервный режим.

## Как пользоваться

1. Вставьте объявление целиком и нажмите «Разобрать текст».
2. Проверьте автоматически заполненные поля. Галочка рядом с каждым полем скрывает его в сторис, не сдвигая остальные блоки.
3. В блоке «Оформление и компоновка» выберите одну из четырёх схем коллажа, от 3 до 7 фото, готовую палитру или свои цвета. Здесь же включаются логотип и подпись под ним.
4. Добавьте фотографии. Первая сторис объединит выбранное количество первых кадров.
5. Следующие сторис показывают фотографии со второй и далее крупным планом. Последней всегда добавляется фирменная сторис с другими предложениями и преимуществами «Титан Авто».
6. Перетаскивайте миниатюры, чтобы поменять порядок и назначить главное фото. В коллаже нажмите нужную ячейку, затем двигайте снимок; колесо мыши меняет масштаб.
7. Верхняя кнопка сохраняет всю серию отдельными PNG через системное меню телефона, нижняя — только открытую сторис.
8. Перед финальной страницей выберите один из пяти дизайнов. Тексты выбранного варианта настраиваются в блоке под выбором дизайна.

Фирменный логотип добавляется автоматически и меняет цвет основной надписи для контраста с фотографией. Текстовые настройки сохраняются в браузере автоматически; сами фотографии не сохраняются.

Тяжёлые фотографии, включая современные снимки с iPhone, перед отрисовкой обрабатываются по очереди: ориентация учитывается, длинная сторона уменьшается до 2560 px, изображение сохраняется в JPEG с качеством 0,88 без EXIF и других лишних метаданных. Во время обработки показывается прогресс, поэтому не нужно заранее сжимать снимки вручную.

Переключатель «Автомобиль продан» включает отдельный позитивный макет завершённой сделки. Название автомобиля сохраняется, срок редактируется, тексты выбираются из пресетов или меняются вручную. Обычные тексты не перезаписываются и возвращаются при выключении режима.

## Пакет нескольких автомобилей

Переключатель «Один автомобиль / Несколько автомобилей» расположен в начале редактора. В пакетном режиме:

1. Каждый автомобиль имеет собственные тексты, цены, палитру, статус «Продано», положение кадров и до 7 фотографий.
2. На экране редактируется только одна машина. Остальные сохраняются в локальной базе браузера, поэтому интерфейс не перегружается.
3. При переходе к другой карточке текущая автоматически сохраняется и выгружается из оперативной памяти.
4. Кнопка «Скачать все главные ZIP» создаёт по одной главной сторис для каждого автомобиля. Большие подборки разбиваются на ZIP по 12 сторис, чтобы не переполнять память.
5. Данные не отправляются в интернет. Для надёжности важную подборку также рекомендуется сохранять через блок архива проекта.

## Архив проектов

Блок «Архив и повторное редактирование» работает локально, без сервера. В Chrome или Edge нажмите «Подключить „Готовые сторис“» и вручную подтвердите нужную папку. Путь нельзя выбрать автоматически из-за защиты Windows и браузера.

Структура архива:

```text
Готовые сторис/
├─ ! Главные сторис/
│  └─ <автомобиль> — <дата> — Главная.png
└─ ! Серии сторис одного авто/
   └─ <автомобиль> — <дата>/
      ├─ project.json
      ├─ Фото/ (оптимизированные JPEG)
      └─ Сторис/
```

`project.json` хранит все тексты, галочки, палитру, режим «Продано», компоновку, порядок фото, их смещение и масштаб. Оптимизированные фотографии встроены в JSON, поэтому его можно открыть отдельно. При открытии папки автомобиля берётся находящийся в ней `project.json`. Повторное сохранение обновляет эту же папку проекта.

## Публикация

Проект рассчитан на GitHub Pages и не требует сервера или базы данных. Фотографии обрабатываются локально в браузере пользователя и не отправляются на хостинг.
