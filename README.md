# Генератор материалов ТИТАН АВТО

Принятая рабочая версия: 21 октября 2026 года.

## Запуск

Откройте index.html в Chrome или Edge. Сервер и установка зависимостей для использования не нужны. Фото, шрифты, логотипы и HEIC-декодер обрабатываются локально. При запуске виден короткий экран загрузки; затем сразу открывается собранный интерфейс и восстановленный проект. Старый режим по ?legacy больше не включается.

Навигация: **Проект → Материалы → Экспорт**. Один текущий проект — один автомобиль. В «Проекте» находятся общие данные, фотографии, контакты и три иконки: сохранить полный JSON, открыть проект, очистить текущий проект. Несохранённые данные защищены подтверждением при очистке. Сохранённые файлы и пользовательские архивы не удаляются.

## Материалы и размеры

| Формат | Размер PNG |
|---|---|
| Сторис | 1080 × 1920 |
| Квадрат | 1080 × 1080 |
| Горизонтальный | 1600 × 1200 |
| Видеообложка | 1920 × 1080 |
| Авито | 1280 × 960 |

До 15 общих фотографий; фото, порядок и кадрирование редактируются во вкладке «Фото». Предпросмотр автоматически подстраивается под окно. На телефоне доступны «Настройки / Предпросмотр». Переключение вида не меняет размеры PNG.

Квадраты: семь одиночных кадров и два коллажа по четыре фото; для полной серии нужны 15 фото. Доступны отдельные PNG, ZIP девяти PNG, сетка 3240 × 3240, сохранение и открытие JSON квадратов. Отдельное кадрирование, поворот, цветокоррекция и логотипы сохранены.

Также доступны обложки, покупка с клиентом, отзывы, пруф услуги и пять вариантов финальной сторис. В покупке можно выбрать 1080 × 1920 или 1080 × 1080. «Видео» означает неподвижную обложку 1920 × 1080, не MP4.

## Праздники

В **Материалы → Дизайн** включите «Праздничное оформление». Праздник можно выбрать вручную или оставить автоматический календарь по Europe/Samara. Выбор сохраняется в JSON и автосохранении; старые проекты открываются с выключенным оформлением.

Пять фотографических комплектов соответствуют Новому году, 23 Февраля, 8 Марта, Дню Победы и Дню автомобилиста. Поздравление, прозрачный декор, исходные фотографии и данные автомобиля компонуются в предпросмотре и PNG. Положение текста учитывается при наложении украшений. Исходные фото не перерисовываются. Графика и промпты: [assets/holidays/README.md](assets/holidays/README.md).

Окно скачивания предлагает предпросмотр, копирование поздравления и ссылки. Telegram: https://t.me/titan_auto_63. MAX: https://max.ru/channel_TITAN_AUTO. Для Telegram предлагается только Telegram, для MAX — только MAX, для других площадок — обе ссылки. Памятка и актуальное поздравление не зависят от включения декора картинки.

## Проекты и экспорт

Пользовательский экспорт — PNG без потерь. JPEG/HEIC и другие поддерживаемые фото по-прежнему читаются; прежняя внутренняя оптимизация до 2560 пикселей по длинной стороне сохранена.

Полный JSON включает встроенные фотографии, специальные материалы, оформление, кадрирование и все редакторы. Поддерживается чтение версий v1–v4 и прежних проектов квадратов. При открытии старой подборки можно выбрать отдельный автомобиль; исходная подборка не перезаписывается.

В «Экспорте» доступны текущий PNG и пакеты выбранных/всех готовых материалов. ZIP содержит PNG в каталогах материалов и полный project.json. Выбор «Другие размеры» даёт пять размеров. Сохранение в папку дополнительно создаёт серию PNG, фотографии, JSON и копию главной сторис. Функции шаблонов обложки и отдельный раздел «Управление» из основного интерфейса убраны.

## GitHub Pages и автономная работа

Приложение размещается как статические файлы, включая assets, Логотип и .nojekyll. Оно работает и в подпапке репозитория. После первого успешного открытия Service Worker сохраняет ресурсы для автономной перезагрузки; до заполнения кеша сайту нужен интернет. Локальный index.html работает без сети сразу.

Резервные копии, пользовательские «Готовые сторис», recovery и результаты verification исключены из Git. Перед загрузкой проверьте, что добавлены все новые исходные JS и assets, а не только ранее отслеживаемые index.html/app.js.

## Контрольные проверки

Для проверок нужен Node.js, Playwright и установленный Edge. Полный актуальный прогон: node run-checks.cjs. Результат: verification/release-check-results.json. Девять наборов проверяют запуск без вспышки старого интерфейса, JSON и автосохранение, защиту данных, праздники, фактические PNG/ZIP, очистку, мобильный интерфейс, HTTP-подпапку и автономную перезагрузку.

Устаревшие проверки прежнего интерфейса и временные скрипты миграций удалены. Сведения о реализации: [DESIGN-CODE.md](DESIGN-CODE.md), [SECURITY.md](SECURITY.md), [RELEASE-CHECK-2026-10-21.md](RELEASE-CHECK-2026-10-21.md). История рабочих версий сохраняется в GitHub.
