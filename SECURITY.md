# Безопасность и устойчивость автономного генератора

Генератор работает в браузере из локальной папки или на статическом хостинге. Код не отправляет фотографии и данные автомобиля на внешний сервер. Шрифты, логотипы, эмодзи и HEIC-декодер включены в проект.

## Границы входных данных

- До 15 фотографий на автомобиль. Один исходник — до 50 МБ, до 100 мегапикселей и до 32768 пикселей по стороне. Размеры PNG, JPEG, GIF, WebP и найденных HEIC/AVIF `ispe` проверяются до декодирования; размеры результата также проверяются.
- JSON — до 160 МБ. Проверяются схема, поддерживаемая версия, типы полей, количество фото, подписи, диапазоны настроек и структура квадратов. Неизвестные ключи не переносятся в объекты настроек.
- Изображения из JSON должны быть встроены как `data:image/...`. HTTP/HTTPS, `javascript:`, HTML и ссылки на чужие файлы не принимаются. Имена файлов для восстановления из папки не могут содержать разделители пути.
- SVG логотипы проходят очистку: допускаются только графические элементы и атрибуты, безопасные стили и внутренние ссылки. Скрипты, обработчики событий, внешние ресурсы, `foreignObject` и изменение базового адреса удаляются.
- Фотографии из обычного загрузчика декодируются и пересохраняются в JPEG. Файлы фотографий из JSON получают расширение по MIME-типу; имя из проекта не определяет тип скачанного изображения.

## Сохранность проекта

Новый JSON и связанные логотипы сначала проверяются, все фотографии загружаются во временный набор. Текущий проект заменяется после успешной подготовки. При неудачном декодировании временные ссылки освобождаются, текущие фото остаются доступными.

Во время загрузки, импорта и экспорта редакторы блокируются для мыши и клавиатуры. Обрабатываются отказы декодера, сбои фонового worker, пустой результат экспорта и ошибки записи. Для worker и изображения установлены тайм-ауты; ссылки `blob:` и временные bitmap освобождаются. Операции IndexedDB подтверждаются после завершения транзакции.

Если браузер запретил локальное сохранение или исчерпал квоту, интерфейс сообщает об этом и не показывает успешное сохранение. Полный черновик хранится в IndexedDB вместе с фотографиями, специальными материалами и настройками всех редакторов; сохраняется и предыдущий снимок. Лёгкие настройки остаются в localStorage для совместимости. Проверка ревизии защищает общий черновик от записи устаревшей вкладкой. При конфликте её изменения можно скачать в JSON.

JSON проекта переносит полное состояние; браузер предупреждает о закрытии вкладки с несохранёнными изменениями. Сохранение одного JPG/PNG не заменяет сохранение JSON. Пакетные записи включают фото, общие данные, отдельное кадрирование, настройки квадратов/обложки и специальные материалы. Фотография при замене удаляется только после успешного декодирования нового файла.

Поддерживаются общие JSON v1–v4, square-v1/v2 и cover-v1. Схема основных полей фиксируется до перестройки интерфейса; перенос финальных настроек в Пруфы не исключает их из импорта. QR-коды генерируются локально, допустимые ссылки имеют протокол HTTP/HTTPS и не загружаются с удалённого сервера. Service Worker кеширует только перечисленные статические ресурсы приложения; фотографии и проекты не передаются на хостинг.

## Политика браузера и ограничения

`index.html` содержит Content Security Policy, которая блокирует внешние скрипты, изображения и соединения, объекты, формы и изменение базового адреса. Локальные `data:` и `blob:` разрешены для декодирования и скачивания. `unsafe-inline` разрешён только для стилей. `unsafe-eval` оставлен для встроенного HEIC-декодера heic2any 0.0.4: его код создаёт функции динамически. При замене декодера следует повторно проверить необходимость этого разрешения.

Проверки не дают гарантии поддержки любого существующего кодека или защиты от ошибок самого браузера. Конвертер HEIC может не поддержать редкие варианты HEIF; большие изображения требуют памяти даже при ограничении размеров. Во время импорта браузер разбирает JSON в памяти. Используйте актуальный браузер и сохраняйте отдельную копию JSON важных проектов.

## Проверки

- `check-security.cjs`: неверные схемы и версии, лишние фото, внешние адреса, обход путей, повреждённое второе фото без потери текущего проекта, SVG, ограничения текста и размеров, отказ локального хранилища, блокировка операций и пакетное кадрирование.
- `check-exports.cjs`: размеры пяти PNG, точное совпадение с предпросмотром, JPG и JSON внутри ZIP, переносимый JSON обложки, сохранение данных при применении шаблона, мобильная ширина.
- `check-formats.cjs`: работа из `file://` без интернета, HEIC, 1–15 фото, цены, штампы и восстановление JSON.
- `check-square-current.cjs`, `check-cover-offline.cjs`: существующая квадратная серия, перестановка и кадрирование, оформление, локальные шрифты.
- `check-data-protection.cjs`, `check-unified-export.cjs`, `check-project.cjs`: полный цикл JSON/ZIP, ошибки хранилища, конфликты вкладок, закрытие браузера и откат импорта.

Для браузерных проверок нужен Playwright и установленный Edge. Они не требуются для самого генератора.
